# Локальный архив документации WB и Ozon

Снимок официальных источников от **17.11.2026**. Обе страницы успешно
прочитаны в браузере; для документации ключи продавцов не нужны.

| Площадка | Сохранено | Операций |
|---|---|---:|
| Wildberries | Все 13 опубликованных YAML OpenAPI из меню Swagger | 311 |
| Ozon | Все операции отрисованной документации Seller API | 497 |

Основной каталог: [все методы и пути](routes.md), [CSV](routes.csv).
CSV содержит площадку, HTTP-метод, путь, серверы, operation ID, название
и ссылку. Индекс WB дополнительно сохраняет теги, deprecated, security
и исходный YAML. Переменные серверов остаются в `servers` и спецификациях.
Старые версии и устаревшие методы сохранены, если они есть в источниках.
Наличие метода в архиве не означает, что он реализован или доступен ключу.

## Wildberries

- [Источники всех 13 спецификаций](wb/sources.json).
- [Машиночитаемый индекс](wb/operations.json).
- Исходные `wb/01-general.yaml` — `wb/13-finances.yaml`: схемы, примеры,
  параметры, серверы, лимиты и авторизация в опубликованном виде.
- [Текст общего раздела](wb/general-documentation.txt).
- [Официальная документация](https://dev.wildberries.ru/docs/openapi/api-information).
- [Официальный Swagger](https://dev.wildberries.ru/swagger/general).

YAML скачаны через `swagger.yaml` в официальном Swagger. Оригиналы
сохранены без изменений, SHA-256 включены в манифест.

## Ozon

- [Все 497 операций](ozon/operations.json): метод, путь, operation ID,
  название и ссылка на конкретный раздел.
- [Текстовый снимок документации](ozon/documentation.txt).
- [Официальная документация](https://docs.ozon.ru/api/seller/).

Индекс извлечён из всех DOM-разделов `id="operation/..."` после загрузки
страницы. У каждой операции проверены HTTP-метод и путь. Служебный
параметр перенаправления `__rr` исключён из ссылок.

**Это не исходная OpenAPI-спецификация Ozon.** Открытая ссылка на её
экспорт на странице не обнаружена. Текстовый снимок отражает состояние
страницы: вложенные свёрнутые поля схем могут в него не входить.
Перед реализацией адаптера нужно раскрыть и прочитать соответствующую
схему в документации. Сохранены также бета-разделы и Ozon Доставка;
индекс не обещает одинаковые права и лимиты для всех разделов.

## Проверка и пересборка

```powershell
uv run scripts/index_api_contracts.py
uv run scripts/index_api_contracts.py --check
```

Python 3.12+ и PyYAML 6.0.3; зависимость объявлена в PEP 723 заголовке
скрипта. Он работает с локальными файлами, не обращается к API и не
требует БД. Пересобирает индекс WB, Markdown/CSV и [манифест](manifest.json).
`--check` проверяет актуальность индексов и SHA-256 источников.
Та же проверка включена в отдельную задачу CI `api-contracts`.

Для обновления заново сохраните официальные источники обеих площадок
и дату снимка в `wb/sources.json` и `ozon/operations.json`, затем
пересоберите индекс. Не подменяйте Ozon-индекс ответом блокировки
или неполностью загруженной страницей.

Повторяемое извлечение Ozon:
[функция чтения DOM](../../scripts/capture_ozon_api.js).
Её нужно выполнить в загруженной вкладке официальной документации,
вызвав `captureOzonApiSnapshot("YYYY-MM-DD")`. Поля результата `index`
и `documentationText` сохраняются в соответствующие файлы Ozon.
Функция проверяет домен, наличие маршрутов и уникальность operation ID;
внутреннее состояние Redoc и cookies не читает.

Архив предназначен для разработки этой интеграции. Условия использования
и права на исходную документацию остаются у соответствующих площадок.
